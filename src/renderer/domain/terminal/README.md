# renderer/domain/terminal

**终端页**（标签页「终端」，`/terminal`）—— 出问题第一眼看这里。

| 文件 | 作用 |
| --- | --- |
| `TerminalView.vue` | 日志列表 + 清空 |

> 原名 `LogView.vue`，目录原名 `logs/`。改名是因为标签页上写的是「终端」，
> 而 `log` 怎么翻译都不是「终端」。

## 内容是什么

主进程日志环形缓冲的镜像：dsh 子进程的 stdout/stderr（启动、就绪地址、
插件加载报错、退出码）+ 启动器的操作事件。

每行带来源前缀（`[dsh 0.1.7]` / `[启动器]` / `[桌面端]`），
一眼能看出是 dsh 说的还是启动器说的。

## 缓冲在主进程，不在渲染层

这样切换页面不会丢、重开窗口也能补齐。进页面时取一次快照，之后订阅实时行。
上限 3000 行（dsh 跑久了会持续输出，无上限的数组会一路吃内存）。

## 「清空」清的是主进程那份缓冲

不只是清视图 —— 否则下次进入页面历史又"复活"，看起来像清空没生效。

## 通道叫 `log:*`，目录叫 `terminal`

通道名是线上协议（主进程与 preload 靠它对接），不跟着目录改名。
但 **i18n 区块名跟着标签页**：`terminal.clear` 而不是 `log.clear`。
