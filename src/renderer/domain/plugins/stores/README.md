# renderer/domain/plugins/stores

插件页的两个 Pinia store。**都只服务插件页**（控制页只是复用 `PluginPanel` 组件，
数据仍走这两个 store）。

| 文件 | 作用 |
| --- | --- |
| `plugins.ts` | 已装插件清单与开关状态 |
| `market.ts` | 市场目录、搜索/排序/筛选/分页、更新判定（这个领域的重心） |

## `market.ts` 里的关键判断

- **「已装」必须按 `npm` 字段比**，不能用短名 —— 目录里存在不同作者的同名短名
  （实测 186 个短名重复，`dsh-pet` 就有两位作者各一份），按短名匹配会把别人的包
  也标成已装，版本与更新目标也跟着错。
- **更新判定用 `@utils/version`**（与主进程同一份实现），
  不再用原先那个"只比数字段"的简化版 —— 它会把 `0.2.0-rc.2` 判成比 `0.2.0` 新。
- **分页 `PAGE_STEP = 120`**：目录有四千余条，一次全渲染会把界面拖死。
