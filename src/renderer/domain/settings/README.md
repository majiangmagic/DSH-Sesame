# renderer/domain/settings

**设置页**（标签页「设置」，`/settings`）。

| 文件 | 作用 |
| --- | --- |
| `SettingsView.vue` | 启动方式 / 端口 / 数据目录 / 快照目录 / 版本池 / 自启 / 语言 / 额外参数 + **启动器更新** |

## 启动器更新（页面底部）

打开页面就查一次（`checkLauncherUpdate` **不抛异常**，一次网络失败不该让整页报错），
所以按钮上直接显示"更新到 x.y.z"，不用用户先点一下。

- 有新版 → 主按钮是「更新到 x.y.z」，点了就下载 → 校验 → 静默安装 → 应用退出并由安装器重启；
- 已最新 → 显示「已是最新版本。」；
- 开发模式 → 主进程直接拒绝，页面显示原因（跑的是源码目录，不能被安装包覆盖）。

**注意**：`installLauncherUpdate()` 成功时 **Promise 不会 resolve**（应用要退出了），
所以界面只处理失败分支，**不要写"更新成功"这种提示**。

进度靠 `onLauncherUpdateProgress` 订阅，订阅放在 `onMounted`、退订放在 `onBeforeUnmount` ——
放在 `runUpdate` 里会漏掉"安装"阶段才到的进度。

## 为什么这一页只有这八项

原版有九项，其中四项**对这个启动器没有对应物**，已删除：

- **管理页端口** —— 原版的界面本身是个本地 HTTP 服务，端口可能被占所以要能改；
  本应用的界面是 Electron 窗口、没有自己的服务，所以没有对应物。
  取而代之的是**启动端口**：它管的是 dsh web 服务绑哪个端口。
- **版本目录** —— 版本池刻意固定在应用旁边，这是"便携、可整份删掉重建"的前提。
- **兼容模式** —— 对应原版"启动失败自动禁用插件并重试"，那套逻辑没有移植，留着是空开关。
- **插件市场** —— 市场是内置库（`dshmarket`），不是能开关的东西。

## 「启动 profile」的下拉是刻意留的占位

`web` / `tui` / `desktop` 可选，`headless` 等禁用（不能在启动器窗口里跑，
dsh 不会打印就绪地址，只会得到一句没有信息量的"启动超时"）。

## 选目录必须走主进程

渲染层没有 Node，拿不到原生文件选择器 —— 走 `window.sesame.window.pickDirectory()`。
**取消时不要清空已有值**：用户按了取消，不是要清掉。

## 语言切换用的是 stores/locale

不在这里 —— 它改的是全局 i18n 实例与 `document.documentElement.lang`，
设置页只是它的**编辑入口**。见 [../../stores/README.md](../../stores/README.md)。
